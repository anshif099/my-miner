# Personal Miner Controller

Phase 2 foundation for a private, multi-device cryptocurrency mining controller. It contains a Firebase-backed web dashboard, trusted Cloud Functions, strict Realtime Database rules, shared contracts, and local-emulator tests.

**Real mining is not implemented yet.** Controls are deliberately disabled and no performance, earnings, or compatibility values are fabricated.

See [docs/setup.md](docs/setup.md) to run the project locally.
